as of 2026-09-23 · Q1–Q2 assumed · Q3, Q4, Q2c decided · Q5, Q6 pending · Phase A prototyped in site repo · B, C next

The decisions the engine actually makes for one detached, new-construction ADU on a lot with an existing house. Inputs are the labeled lot edges, the jurisdiction's published ordinance, and two unit facts.

Scope assumptions → Linear

  • FOR-1419Zone allows residential use, and the lot holds a single-family dwelling. Flags zone_use_assumed_residential, dwelling_type_assumed_sfr. Multifamily = out of scope.
  • FOR-1420Parcel is not an SB 9 lot split at its two-unit cap. Manual yes/no, default no. Flag sb9_split_assumed_no.
  • FOR-1421No detached ADU exists on the lot yet, so the §66323(a)(2) entitlement is open. Manual yes/no, default no. Flag existing_detached_adu_assumed_no.
  • FOR-1422Transit proximity is tested against the Caltrans HQ Transit Area half-mile straight-line buffers (existing stops only); the statute says walking distance. Flag transit_straight_line_buffer. Refinement: Google walking distance to the nearest HQ stops.
  • FOR-1418Parent: values extraction. Full-ordinance corpus scrape (3 tiers) running in a separate session.

Decided, and what was rejected

  • Q1 · assumed yesThe lot is eligible. Detached, new construction only — conversions, attached ADUs and JADUs are not FormX products.
  • Q2 · assumed yesA published ADU ordinance is in effect; no status lookup. Sources of truth: the codified ordinance and Gov. Code §§ 66310–66342 read with the HCD Handbook (Mar 2026). Rejected as sources: HCD review letters, Zoneomics data.
  • Q3Size fork at 800 sf of interior livable space. Height: ≤ 16 ft anywhere; 16–18 ft inside a CA HQ Transit Area; > 18 ft → local track. The 20 ft roof-pitch allowance is left to a human override in the Gaudi UI. Both unit inputs manual and required; names follow Gaudi: unit_size, unit_height_in_feet.
  • Phase APrototyped in the site repo (2026-09-23): services/compute/adu_setbacks/, services/parcel_data/ca_transit_client.py, POST /adu/evaluate, debug-UI inputs and the FOR-438 red band. 126 unit tests green; verified on a live Sunnyvale lot.
  • Q4Inside the local track, a unit ≤ 800 sf and ≤ 16 ft is shielded: front setback, coverage, FAR and open space cannot preclude it (§66321(b)(3)).
  • Street sideA street_side edge is a side (state 4 ft cap applies) unless the jurisdiction is all_fronts, where the labeler's second_front flag makes it a front. No per-jurisdiction field needed.
  • TracksEnvelopes are computed as packages — no cherry-picking provisions across the state and local tracks. Build order: Phase A state track → Phase B local track → Phase C choice.
